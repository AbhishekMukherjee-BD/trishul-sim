## 5. MULTI-PART ARCHITECTURAL BREAKDOWN (Rule R11)
Project TRISHUL-SIM is composed of **two coordinated, zero-cloud runtime layers**:
1. **Frontend Simulation & C2 Console** (`/src`, `/index.html`, `/vite.config.js`):
   - High-performance React 19 + Three.js 0.174 client running at 60 FPS.
   - Executes Reynolds Boids flocking swarm physics locally in the browser's JavaScript engine.
   - Renders dual 3D viewports: 3D AESA Radar PPI scope and Electro-Optical/Infrared (EO/IR) FLIR camera.
2. **Backend MAVLink & Telemetry Bridge** (`/server/app.py`):
   - Zero-dependency Python 3 HTTP server running on standard library `http.server` and `socketserver`.
   - Simulates bi-directional MAVLink v2.0 military telemetry packets (`GLOBAL_POSITION_INT`, `ATTITUDE`).
   - Evaluates simulation telemetry against DSSC air-defence doctrine via local Ollama LLM (`mistral`).
