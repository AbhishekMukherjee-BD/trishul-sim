## 1. VERIFIED INSTALLATION & LAUNCH STEPS

- [VERIFIED-READ] **System Prerequisites**:
  - Node.js `>= 18.0.0` (tested on `v22.11.0`)
  - Python `3.x` (tested on `3.14.7`; requires **zero** pip packages)
  - Ollama installed locally with `ollama pull mistral`
- [VERIFIED-READ] **Environment Variables**: None required (`0` `.env` files; 100% self-contained).
- [VERIFIED-READ] **External Accounts Required**: None (`0` cloud logins or tokens).

### 3-Step Execution Sequence
```bash
# Terminal 1: Start Python MAVLink Telemetry Bridge
python3 server/app.py

# Terminal 2: Ensure Local Ollama Engine is Running
ollama serve   # (or launch Ollama application)

# Terminal 3: Install & Start Frontend Command Center
npm install
npm run dev
```
Open **`http://localhost:5173`** in Chrome, Edge, or Safari.

To execute the automated regression test suite:
```bash
npm test
```
